Algoritmo e Lógica de Programação

Professora: Prof.ª Waldinelly Costa

Disciplina que desenvolve o raciocínio lógico necessário para a construção de algoritmos, base para o aprendizado de qualquer linguagem de programação. Livro-texto: Forbellone e Eberspächer, Lógica de Programação: a construção de algoritmos e estruturas de dados (3ª ed.).

Aulas

DataTemaO que foi aprendido
19/08/2026 Introdução à disciplina Primeira aula com a Prof.ª Waldinelly. Conceito de algoritmo, variáveis e tipos primitivos, com uma comparação inicial entre Portugol e Python (conteúdo bem introdutório). Ao final da aula foi passado um trabalho de apresentação para as próximas semanas.
26/08/2026 Apresentações dos trabalhos (parte 1) Apresentação, pelos alunos, do trabalho passado na aula anterior.
02/09/2026 Apresentações dos trabalhos (parte 2) Continuação das apresentações dos trabalhos.
09/09/2026 Estruturas de seleção (SE / E / OU) Aula ministrada por um professor de Matemática da Fatec (que leciona em outros semestres), convidado para explicar a lógica condicional (SE, E, OU) de uma forma diferente. Depois houve um coffee break e, em seguida, uma palestra.
