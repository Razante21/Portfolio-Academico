1.1

Dado o vetor V preenchido com os valores 2, 6, 8, 3, 10, 9, 1, 21, 33 e 14 (posições 1 a 10), e X = 2, Y = 4, obtenha o valor de várias expressões de acesso ao vetor.

Portugol

algoritmo "ex1_1"
var
   V: vetor[1..10] de inteiro
   X, Y: inteiro
inicio
   V[1] <- 2
   V[2] <- 6
   V[3] <- 8
   V[4] <- 3
   V[5] <- 10
   V[6] <- 9
   V[7] <- 1
   V[8] <- 21
   V[9] <- 33
   V[10] <- 14
   X <- 2
   Y <- 4

   escreval("a) ", V[X + 1])
   escreval("b) ", V[X + 2])
   escreval("c) ", V[X + 3])
   escreval("d) ", V[X * 4])
   escreval("e) ", V[X * 1])
   escreval("f) ", V[Y * 2])
   escreval("g) ", V[X * 3])
   escreval("h) ", V[V[X + Y]])
   escreval("i) ", V[X + Y])
   escreval("j) ", V[8 - V[2]])
   escreval("l) ", V[V[4]])
   escreval("m) ", V[V[V[7]]])
   escreval("n) ", V[V[1] * V[4]])
   escreval("o) ", V[X + 4])

1.2

Leia 20 valores para os vetores A e B e 20 operadores (+, -, * ou /) para o vetor OP. Calcule, para cada posição, o resultado da operação entre A[i] e B[i] indicada por OP[i], guardando em R.

Portugol

algoritmo "ex1_2"
var
   A, B: vetor[1..20] de inteiro
   OP: vetor[1..20] de caractere
   R: vetor[1..20] de real
   i: inteiro
inicio
   para i de 1 ate 20 faca
      leia(A[i])
   fimpara
   para i de 1 ate 20 faca
      leia(B[i])
   fimpara
   para i de 1 ate 20 faca
      leia(OP[i])
   fimpara

   para i de 1 ate 20 faca
      se OP[i] = "+" entao
         R[i] <- A[i] + B[i]
      fimse
      se OP[i] = "-" entao
         R[i] <- A[i] - B[i]
      fimse
      se OP[i] = "*" entao
         R[i] <- A[i] * B[i]
      fimse
      se OP[i] = "/" entao
         R[i] <- A[i] / B[i]
      fimse
   fimpara

   para i de 1 ate 20 faca
      escreval(R[i])
   fimpara
fimalgoritmo

Python

A = []
B = []
OP = []
R = []

for i in range(20):
    A.append(int(input("A: ")))
for i in range(20):
    B.append(int(input("B: ")))
for i in range(20):
    OP.append(input("Operação (+ - * /): "))

for i in range(20):
    if OP[i] == "+":
        R.append(A[i] + B[i])
    elif OP[i] == "-":
        R.append(A[i] - B[i])
    elif OP[i] == "*":
        R.append(A[i] * B[i])
    else:
        R.append(A[i] / B[i])

print(R)
1.3

Leia 20 valores reais para os vetores A e B (sem zeros em B) e calcule A[k] × (1 / B[k]) para cada posição, guardando o resultado em R em ordem intercalada (posições pares do índice de origem vão para a metade final de R, ímpares para a inicial).

Portugol

algoritmo "ex1_3"
var
   A, B, R: vetor[1..20] de real
   i, k: inteiro
inicio
   para i de 1 ate 20 faca
      leia(A[i])
   fimpara
   para i de 1 ate 20 faca
      leia(B[i])
   fimpara

   para k de 0 ate 19 faca
      se k mod 2 = 0 entao
         R[10 - k \ 2] <- A[k + 1] * (1 / B[k + 1])
      senao
         R[11 + k \ 2] <- A[k + 1] * (1 / B[k + 1])
      fimse
   fimpara

   para i de 1 ate 20 faca
      escreval(R[i])
   fimpara
fimalgoritmo

Python

A = []
B = []
R = [0] * 20

for i in range(20):
    A.append(float(input("A: ")))
for i in range(20):
    B.append(float(input("B (não use 0): ")))

for k in range(20):
    valor = A[k] * (1 / B[k])
    if k % 2 == 0:
        R[9 - k // 2] = valor
    else:
        R[10 + k // 2] = valor

print(R)
1.4

Leia 20 valores para o vetor V e ordene-o em ordem crescente usando o método da seleção direta (encontrar o menor elemento restante e trocá-lo de posição a cada passo).

Portugol

algoritmo "ex1_4"
var
   V: vetor[1..20] de inteiro
   i, j, menor, aux: inteiro
inicio
   para i de 1 ate 20 faca
      leia(V[i])
   fimpara

   para i de 1 ate 19 faca
      menor <- i
      para j de i + 1 ate 20 faca
         se V[j] < V[menor] entao
            menor <- j
         fimse
      fimpara
      aux <- V[i]
      V[i] <- V[menor]
      V[menor] <- aux
   fimpara

   para i de 1 ate 20 faca
      escreval(V[i])
   fimpara
fimalgoritmo

Python

V = []
for i in range(20):
    V.append(int(input("Valor: ")))

for i in range(19):
    menor = i
    for j in range(i + 1, 20):
        if V[j] < V[menor]:
            menor = j
    aux = V[i]
    V[i] = V[menor]
    V[menor] = aux

print(V)

Leia 20 valores para o vetor V e ordene-o em ordem crescente usando o método da bolha (comparar pares vizinhos e trocá-los quando estiverem fora de ordem, repetindo até o vetor ficar ordenado).

Portugol

algoritmo "ex1_5"
var
   V: vetor[1..20] de inteiro
   i, passo, aux: inteiro
inicio
   para i de 1 ate 20 faca
      leia(V[i])
   fimpara

   para passo de 1 ate 19 faca
      para i de 1 ate 19 faca
         se V[i] > V[i + 1] entao
            aux <- V[i]
            V[i] <- V[i + 1]
            V[i + 1] <- aux
         fimse
      fimpara
   fimpara

   para i de 1 ate 20 faca
      escreval(V[i])
   fimpara
fimalgoritmo

Python

V = []
for i in range(20):
    V.append(int(input("Valor: ")))

for passo in range(19):
    for i in range(19):
        if V[i] > V[i + 1]:
            aux = V[i]
            V[i] = V[i + 1]
            V[i + 1] = aux

print(V)
