# Portfólio Acadêmico

Portfólio digital do curso de **Tecnologia em Desenvolvimento de Software Multiplataforma**, da
Fatec Indaiatuba "Dr. Archimedes Lammoglia". Organizado por semestre, com as matérias cursadas e as
atividades desenvolvidas em cada uma.

🔗 **Acesse o site publicado:** https://razante21.github.io/Portfolio-Academico/

## Sobre este projeto

Este repositório contém a **Avaliação P1** da disciplina de Algoritmo e Lógica de Programação
(professora Me. Waldinelly Martha Alves Costa), que pede:

- **Item A** — lista de exercícios resolvidos dos capítulos 1 e 2 do livro-texto (Forbellone e
  Eberspächer, *Lógica de Programação*);
- **Item B** — resumo do capítulo 3 (Estruturas de Controle) + 4 exercícios de exemplo;
- **Item C** — tudo publicado em um portfólio digital (este site).

Os algoritmos foram escritos em **VisuAlg** (Portugol).

## Estrutura do site

```
portfolio/
├── index.html              → página inicial
├── sobre.html               → curso, integrantes do grupo, experiência profissional
├── projetos.html            → projetos do grupo
├── eventos.html             → eventos acadêmicos
├── referencias.html         → bibliografia utilizada
├── contatos.html            → como falar com o grupo
├── css/
│   └── style.css            → estilo compartilhado por todas as páginas
└── semestre1/
    └── algoritmo-logica-programacao/
        ├── index.html        → página da matéria (aulas, atividades)
        └── p1/
            ├── index.html               → atividade P1
            ├── exercicios-cap1-cap2.pdf → item A
            └── resumo-cap3.pdf          → item B
```

## Tecnologias

- HTML e CSS puro (sem frameworks, sem build)
- Hospedagem via [GitHub Pages](https://pages.github.com/)
- Controle de versão com Git

## Como editar

Basta alterar os arquivos `.html`/`.css` diretamente (localmente ou pelo editor do próprio GitHub) e
enviar (`push`) para a branch `main` — o GitHub Pages atualiza o site publicado automaticamente em
poucos minutos.
