Capítulo 3 — Estruturas de Controle

Resumo

O capítulo 3 apresenta as três estruturas básicas que controlam o fluxo de execução de um algoritmo: a estrutura sequencial, a estrutura de seleção e a estrutura de repetição. Qualquer algoritmo, por mais complexo que seja, pode ser construído combinando essas três estruturas.

Estrutura sequencial

É o fluxo mais simples: as ações são executadas uma após a outra, na ordem em que foram escritas, de cima para baixo. Cada ação é separada por ponto-e-vírgula. O modelo geral de um algoritmo segue o padrão: início → declaração de variáveis → corpo do algoritmo (ações) → fim.

Estrutura de seleção

Permite que uma ação (ou bloco de ações) seja executada apenas se determinada condição for satisfeita. Existem quatro variações:

  • Seleção simples (se ... então ... fimse): executa a ação somente se a condição for verdadeira.
  • Seleção composta (se ... então ... senão ... fimse): executa um bloco se a condição for verdadeira e outro se for falsa.
  • Seleção encadeada: várias seleções agrupadas, podendo ser homogêneas (seguem um padrão, tipo se-senão-se) ou heterogêneas (sem padrão fixo).
  • Seleção de múltipla escolha (escolha ... caso ... fimescolha): substitui uma seleção encadeada homogênea quando uma mesma variável é testada contra vários valores discretos.

Estrutura de repetição

Permite repetir um trecho do algoritmo (laço ou loop) enquanto ou até que uma condição seja satisfeita. Existem três formas:

  • enquanto ... faça ... fimenquanto — teste no início: a condição é verificada antes de cada execução; o bloco pode não ser executado nenhuma vez.
  • repita ... até — teste no final: a condição é verificada depois do bloco; o bloco é executado ao menos uma vez.
  • para ... de ... até ... passo ... faça ... fimpara — usada quando o número de repetições é conhecido de antemão, com uma variável de controle que é incrementada (ou decrementada) automaticamente a cada iteração.

Nas estruturas de repetição são fundamentais os conceitos de contador (variável que soma sempre a mesma quantidade constante, normalmente 1) e acumulador (variável que soma um valor que pode ser diferente a cada iteração), além dos critérios de parada por condição ou por valor finalizador pré-combinado.

Quatro exercícios de exemplo

A seguir, um exemplo de cada estrutura estudada no capítulo: sequenciação, seleção e duas variações de repetição.

Exemplo 1 — Estrutura Sequencial

Elabore um algoritmo que calcule a área de um círculo qualquer, dado o raio.

início
    real: R, Area;
    leia (R);
    Area ← 3,14 * pot(R,2);
    escreva (Area);
fim.

Todas as ações (ler o raio, calcular a área e mostrar o resultado) são executadas uma única vez, em sequência, sem nenhum desvio de fluxo — por isso é um exemplo puro de estrutura sequencial.

Exemplo 2 — Estrutura de Seleção

Escreva um algoritmo que, a partir de um mês fornecido (1 a 12), apresente o nome por extenso ou uma mensagem de mês inválido.

início
    inteiro: Mes;
    leia (Mes);
    escolha Mes
        caso 1: escreva ("Janeiro");
        caso 2: escreva ("Fevereiro");
        caso 3: escreva ("Março");
        caso 4: escreva ("Abril");
        caso 5: escreva ("Maio");
        caso 6: escreva ("Junho");
        caso 7: escreva ("Julho");
        caso 8: escreva ("Agosto");
        caso 9: escreva ("Setembro");
        caso 10: escreva ("Outubro");
        caso 11: escreva ("Novembro");
        caso 12: escreva ("Dezembro");
        caso contrário: escreva ("Mês inválido");
    fimescolha;
fim.

Aqui usamos a seleção de múltipla escolha, ideal quando uma mesma variável (Mes) é testada contra vários valores discretos.

Exemplo 3 — Estrutura de Repetição (enquanto)

Construa um algoritmo que verifique se um número fornecido pelo usuário é primo.

início
    inteiro: N, I, Divisores;
    leia (N);
    Divisores ← 0;
    I ← 1;
    enquanto (I <= N) faça
        se (N mod I = 0)
        então
            Divisores ← Divisores + 1;
        fimse;
        I ← I + 1;
    fimenquanto;
    se (Divisores = 2)
    então
        escreva ("Primo");
    senão
        escreva ("Não primo");
    fimse;
fim.

O laço enquanto percorre todos os números de 1 até N, contando quantos são divisores de N. Se apenas dois divisores forem encontrados (1 e o próprio número), N é primo.

Exemplo 4 — Estrutura de Repetição (mais elaborada — série de Fibonacci)

Escreva um algoritmo que gere a série de Fibonacci (1, 1, 2, 3, 5, 8, 13, ...) até o vigésimo termo.

início
    inteiro: F1, F2, FN, I;
    F1 ← 1;
    F2 ← 1;
    escreva (F1);
    escreva (F2);
    para I de 3 até 20 passo 1 faça
        FN ← F1 + F2;
        escreva (FN);
        F1 ← F2;
        F2 ← FN;
    fimpara;
fim.

Este exemplo é mais elaborado porque, além de repetir um bloco um número fixo de vezes (estrutura para), a cada iteração é necessário atualizar duas variáveis auxiliares (F1 e F2) para "deslizar" a sequência e obter o próximo termo — combinando repetição com lógica de acumulação de estado.
