Portfólio Digital — Avaliação P1 de Algoritmo e Lógica de Programação

Este próprio site é o meu primeiro projeto no curso: um portfólio digital publicado no GitHub Pages, reunindo os exercícios resolvidos dos capítulos 1 e 2 e o resumo do capítulo 3 do livro de Forbellone e Eberspächer (resolvidos em grupo, conforme pedido pela professora), além das demais seções exigidas pela avaliação.

Ferramentas utilizadas: HTML e CSS puro, hospedagem via GitHub Pages, controle de versão com Git.
